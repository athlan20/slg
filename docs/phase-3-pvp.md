# 第三期：玩家对抗

决策日期：2026-10-03。本文记录三期玩家对抗（PvP）已拍板的规则与实现落点，对应云效 AISLG-122 / 123 / 124，协议 v38~v40。替代 [`phase-1-launch-scope.md`](phase-1-launch-scope.md) 中「玩家对抗、占城与保护」一节的旧草案。

文中数值已经过 AISLG-126 模拟校准（2026-10-03，见 [`battle-calibration.md`](battle-calibration.md)），标「校准后维持」或「v42 校准」。

## 设计前提

- **Agent 全天在线。** 玩家下线后，接入的 Agent 照样能出兵；没接 Agent 的玩家处于劣势。所以保护全部做成服务端硬规则（时长、比例、冷却），不依赖「防守方醒着」。
- **没有联盟和聊天。** 攻城不能依赖多人集结，一个人打几次就要能打下来。
- **服务端不跑 Agent。** 防守方的自动化只靠规则：驻军自动守城、烽火台预警推送给玩家及其 Agent。服务端不替任何一方做决策。

## 掠夺玩家城（AISLG-122，v38）

- 可以侦察、掠夺其他玩家的主城和分城（`MARCH task=plunder`）。和 NPC 袭击主城一样走守城战：城墙、箭塔、城守武将、城防科技都生效。
- 防守方收到来袭预警（推送 2017 `PUSH_ATTACK_WARNING`，详细程度按烽火台等级分档），预警期间可以增援。战报 `kind=pvp_raid`，双方各一份。
- 可抢量：
  - 四种资源：(存量 − 仓库保护) × **45%**（v42 校准，原 30%），再受负重限制。
  - 金币：存量 × **15%**（v42 校准，原 10%）。
  - 出发城官府比目标城高 **5** 级起，每多 1 级收益 **−15%**，最低 **25%**（校准后维持）。
- 被攻破或被抢后，这座城免战 **4 小时**（校准后维持），玩家和 NPC 都不能再打。与 NPC 袭击共用 `cities.truce_until`。
- 主动免战：op 53 `TRUCE`。

## 抢他人野地（AISLG-123，v39）

- 对他人野地出兵只能选「占领」，「掠夺」被拒（`TASK_INVALID_FOR_TARGET`）。按野地战结算，没有城墙；对方没留驻军就直接拿下。战报 `kind=pvp_wilderness`。
- 打赢后，攻方占领名额有空，地就归攻方；名额已满，地变无主。原主人收到 `wilderness_lost`（`cause=conquest`）。
- 刚换主人的地保护 **1 小时**（校准后维持），期间玩家和 NPC 都不能抢（`TILE_PROTECTED`）。

## 占领他人分城（AISLG-124，v40）

- **城防值**：满值 **100**；任务选「占领」打赢一次（守军全灭）降 **35**，冲车按占比最多再降 **15**（冲车占 10% 拿满）；降到 0 的那一次当场换主人。数值经校准维持。
- 城防值属于城本身，不分攻方：别人打掉前两段、你补最后一次，城就归你。
- 「占领」打赢不掠夺资源，「掠夺」打赢不降城防值。
- 打赢后进入 4 小时免战，免战期间城防值不回涨；免战结束后每小时回涨 **10**（校准后维持）。所以占一座分城至少要打 3 次、跨 8 小时以上。
- 名额条件与占 NPC 城相同。出发时校验；到达时名额没了，这一仗照打，打赢只降城防值、不换主人。主城选「占领」被拒。
- 换主人时：
  - 建筑、资源、名城加成归新主人；城防值回满，保护 **6 小时**（校准后维持）。
  - 排队中的建造、征兵、研究作废，不退资源。
  - 城守卸任。武将是账号级的，仍归原主人。
  - 这座城的野地变无主，驻军回原主人主城；从这座城出发、还在外的部队改回原主人主城。
  - 针对这座城的 NPC 袭击作废。
  - 新事件和全服播报 `city_conquered`，战报 `kind=pvp_conquest`。
