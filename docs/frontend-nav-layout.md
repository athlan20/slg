# 前端界面重构：导航工作区（开发文档）

决策日期：2026-10-02。界面**完全按照** [`frontend/prototypes/nav.html`](../frontend/prototypes/nav.html)（方案 D「导航工作区」）重构现有 React 前端。

本文写给接手开发的人：先在浏览器里打开设计稿点一遍（`cd frontend && npm run dev` 后访问 `/prototypes/nav.html`，或直接双击文件），再读本文。设计稿是静态 DOM + 演示数据，**只当视觉与交互的标准**；正式实现用现有的 React + TypeScript + Tailwind + Rsbuild，数据全部来自现有的会话层（`useGameSession` 等），不新增协议、不改后端。

## 1. 范围

- **做**：页面骨架、导航、七个页面的排版、弹窗取舍、分页列表、断点适配；把现有组件搬进新位置并按需拆分。
- **不做**：改协议 / 后端、改游戏规则或数值、引入路由库 / 状态库 / UI 组件库、Canvas。
- **功能不能少**：现在界面能做的每一件事，重构后都要能做（见第 9 节清单）。

## 2. 硬性规则

1. **任何窗口尺寸都不出现竖向滚动条**——页面本身和面板内部都不滚动（`overflow-y: auto/scroll` 一律不用）。内容放不下就**分页**或**截断（带 `title` 悬停看全文）**，不能靠滚动。登录页除外（内容本来就小）。
2. 外壳锁定一屏：`html, body` 高度 100%、`overflow: hidden`；外壳 `height: 100dvh`；所有网格子项 `min-height: 0; min-width: 0`。
3. 每个功能块都写中文 `role`（AGENTS.md 前端规范）。新块的命名用「页面-区块-子项」，例如 `军队页-征兵-兵种表`。
4. 单文件 ≤ 500 行（手写代码）。现在已经超线或贴线的 `useGameSession.ts`（926）、`worldSession.ts`（782）、`copy.ts`（788）、`WorldMapGrid.tsx`（500）**这次不强制拆**，但不要再往里加东西；新增逻辑放新文件。
5. 配色只用现有主题变量（`bg / panel / panel-2 / line / text / dim / faint / accent / warn / gold / ok …`，见 `src/styles/index.css`），四套皮肤（暗夜 / 赤霄 / 鎏金 / 宣纸）必须都正常。数字用等宽（`font-mono` + tabular-nums）。
6. 文案继续放 `copy*.ts`，不要写死在组件里。

- **侧栏**：顶部城池切换（下拉，列出全部城池：名字 / 等级 / 主城·分城·名城 / 坐标）；中部七个导航项（图标 + 名字 + 角标）；底部账号按钮，菜单里放「城池改名 / 切换账号 / 重置账号 / 皮肤四选一」，按钮上带本人连接状态灯（保留 `顶栏-本人在线状态` 这个 role，见第 8 节）。
- **顶栏**：页面标题 + 六格资源（金粮木石铁 + 人口；每格显示存量、每小时净产量、离满仓百分比与细进度条；≥90% 变警示色）+ 警报胶囊（NPC 来袭 + 倒计时〔红色闪烁，点开来袭提醒〕、断粮倒计时、免战倒计时，没有就不显示）+ 「集市」「榜」按钮。
- **底栏**：所有进行中的事排成一行（建造 / 征兵 / 科技研究 / 行军，每项带剩余时间和底部进度条，放不下的截断），右侧一行最新全服播报，点开看播报历史（弹窗）。

## 4. 导航与状态

- 当前页面存在 `location.hash`（`#overview / #map / #city / #army / #growth / #intel / #agent`，缺省 `#overview`），刷新后停在原页；不引入路由库，写一个 `usePage()` 小 hook（读写 hash + 监听 `hashchange`）。
- 页面之间的跳转：军情摘要里的「定位」→ 跳地图页并居中目标；「去征兵」→ 军队页。
- 角标：总览 = NPC 来袭数（红色）；城池 = 建造队列条数；军队 = 在外行军数；养成 = 进行中的研究数；情报 = 进入情报页后新到的战报数（前端本地记「已看到的最大战报 id」即可）；Agent 无。

## 6. 公共件

- **分页列表** `usePagedList`（新建）：给定容器和条目，**先渲染第一条量真实行高，再按容器可用高度算每页条数**；底部分页器「‹ 1 / 3 ›」固定占位（**量高之前分页器就要占好位**，否则会多算一行——设计稿踩过这个坑）；容器尺寸变化（`ResizeObserver`）时重算；只有一页时分页器显示「共 N 条」。设计稿里的参考实现：`frontend/prototypes/console-right.js` 的 `paged()`。
- **地图格数按容器算**：格子目标宽约 44px，`列 = round(宽 / 44)`、`行 = round(高 / 44)`，容器变化时重算，地图永远刚好铺满（参考 `console-map.js` 的 `renderWorld`）。现有 WorldMapGrid 的缩放与拖拽保留。
- **地图等级数字**：默认隐藏，悬停 / 选中时显示；满级（10 级）用金色常显。
- **截断**：单行文本 `truncate` + `title` 放全文；数值不截断。

## 7. 弹窗规则

**操作就地做，详情才弹窗。**

| 类型 | 用法 | 具体 |
| --- | --- | --- |
| 就地（不弹窗） | 所有会改变游戏状态的操作 | 出征 / 侦察 / 截击 / 运输 / 调兵 / 增援 / 撤回（地图页右侧）、建造升级（城池页右侧）、征兵、研究、招将 / 任命 |
| 弹窗 | 只读、内容多、偶尔看 | 战报详情、侦察报告、排行榜、离线日报（完整）、黄巾之乱详情（营地列表 / 贡献榜 / 奖励）、全服播报历史 |
| 小浮层 | 轻量操作，锚在按钮下 | 集市兑换（「集市」按钮下方，点外面关闭） |
| 确认框 | 不可撤销 | 重置账号、切换账号（现有确认框保留） |
| 提醒 | 必须马上看到 | NPC 来袭（现有 NpcWarningModal 保留，可增援） |

弹窗统一：Esc / 点遮罩关闭；宽度 ≤ 640px（确认框 ≤ 400px）；高度不超过视口；**弹窗内容同样不滚动**，长列表分页。现在会滚动的组件都要改：BattleReportModal、ScoutReportModal、LeaderboardModal、OfflineReportModal、EventsPanel、HeroPanel、TechPanel、CitySwitcher、ServerFeed、YellowTurbanPanel（都用了 `max-h-*` + `overflow-y-auto`）。

## 11. 验收标准

- `cd frontend && npm run typecheck && npm run build` 通过；`npm run test:e2e` 通过。
- 在 **1920×1080、1440×900、1280×720、1100×800、390×844** 五种尺寸下，登录后每个页面（含地图页选中各类目标、城池页选中建筑、弹窗打开时）都满足：
  - `document.documentElement.scrollHeight <= innerHeight`（页面不滚动）；
  - 没有任何元素 `overflow-y` 为 auto / scroll 且内容超出；
  - 没有内容被裁在区块底边外（按钮、最后一行列表都完整可见）。
  可以照 `frontend/prototypes` 评审时用的 Playwright 检查脚本思路写一个 `test/e2e/layout-fit.spec.ts` 自动跑。
- 第 9 节清单逐条可用；四套皮肤下没有看不清的文字或控件。
- 截图与设计稿 `nav.html` 对比：区块位置、比例、信息层级一致（数值与文案以真实数据为准）。

## 11.1 设计调整（2026-10-03）

## 12. 注意

- 仓库是多人 / 多会话并行开发：重构会大面积改 `App.tsx` 和各面板，开工前先拉最新代码，避免和别人的改动冲突；不要动别人未提交的文件。
- 空态（没有行军 / 没有战报 / 没有武将）、加载中、断线重连都要有对应样子，不能出现空白区块。
- 真实数据比演示数据长（城名、事件文本、战报标题），一律截断 + `title`，不要让行高被撑开（会打乱分页的行高测量）。
- 设计稿里账号菜单的「布局方案切换」只用于评审，正式版不要做。
