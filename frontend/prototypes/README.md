# 单页界面样稿

打开 `index.html` 可预览首期全部内容：账号登录、农场状态与建造入口、Agent 信息及最近事件。桌面与手机共用同一页面；无需导航或弹窗。

也可以用前端的 dev server 预览（样稿不参与构建，只是被挂到 `/prototypes/*`，省掉单独起静态服务器）：`cd frontend && npm run dev`，然后访问 <http://localhost:8424/prototypes/index.html>、`/prototypes/city-main.html`、`/prototypes/city-dark.html`。直接双击 HTML 文件打开同样可以，样稿内部只用相对路径引用样式和脚本。

`city-main.html` 是另一份探索稿：参考旧作玩法结构的**城池主界面**，单屏内呈现资源、城内建筑、世界地图、行军、战场、名将、Agent 与事件。它面向完整主界面的布局讨论，不涉及已确定的协议或数值。

页面顶部可切换四套视觉方案，布局完全一致，只有配色与字体不同：

| 文件 | 方案 | 取向 |
| --- | --- | --- |
| `theme-rice.css` | 宣纸朱印 | 浅色国风，暖米底 + 朱红 + 宋体标题 |
| `theme-ink.css` | 水墨 | 纯白底 + 灰阶地形，朱砂只点关键状态，留白最大 |
| `theme-bamboo.css` | 竹简夜 | 深墨底 + 米白字，适合长时间挂机盯盘 |
| `theme-mono.css` | 数据台 | 冷白 + 单一青蓝，几何化，像运营后台 |

`city-main.css` 是布局与结构层，不含具体配色；颜色全部由主题文件里的 CSS 变量提供。新增方案只要再写一个变量文件。

`city-dark.html`（配 `city-dark.css` + `city-dark-themes.css`）是同一完整主界面的**深色极简科技风**独立重设计稿：单一强调色、等宽数字、三栏单屏布局（左：城内/建造/科技，中：世界地图/行军/战场，右：名将/Agent/事件），顶栏为城池/资源/钱包，底条为联盟/今日/城防摘要。与 `city-main.html` 不共享样式，便于对比取舍。

`city-dark.html` 底条可切换四套皮肤，布局完全一致，只有配色不同；选择会存入 localStorage：

| 主题 | 取向 |
| --- | --- |
| 暗夜（默认） | 深灰蓝底 + 单一青色 |
| 赤霄 | 暗红岩底 + 朱红强调，警告转琥珀 |
| 鎏金 | 墨黑底 + 金色强调，适合挂机盯盘 |
| 宣纸 | 浅色米白底 + 朱砂强调，白天友好 |

`city-dark.css` 只引用 CSS 变量；新增皮肤只要在 `city-dark-themes.css` 里复制一个 `[data-theme]` 变量块、再在底条切换器里加一个按钮。

## 单屏布局四套方案（2026-10-02，重构方向稿）

先打开 **`layouts.html`**：四套布局并排缩略预览，点进任意一套。四套共用同一份数据、地图、面板、弹窗与皮肤，只是摆法不同；每套的账号菜单里都能切换皮肤和跳到其他方案。

| 方案 | 文件 | 摆法 | 适合 |
| --- | --- | --- | --- |
| A 三栏控制台 | `console.html` / `console.js` | 左城务 · 中地图 · 右情报 · 底时间线，全部同屏 | 手动玩、要一眼看全的老玩家 |
| B 沉浸地图 | `hud.html` / `hud.css` / `hud.js` | 地图铺满整屏，城务抽屉 / 情报卡 / 指挥条都浮在地图上，可收起 | 地图感最强，最像手游 SLG |
| C 盯盘仪表盘 | `board.html` / `board.css` / `board.js` | 关键指标行 + 等权组件格（城务 / 地图 / 军情 / 进行中 / Agent 托管 / 情报） | Agent 在玩、人来看 |
| D 导航工作区 | `nav.html` / `nav.css` / `nav.js` | 左侧导航切页（总览 / 地图 / 城池 / 军队 / 养成 / 情报 / Agent），每页单屏 | 最好上手、最容易适配手机 |

共用文件：`console-data.js`（演示数据）、`console-map.js`（地图）、`console-views.js`（资源条 / 城务面板 / 时间线 / 全局交互）、`console-right.js`（选中详情与分页列表）、`console-modal.js`（弹窗）、`console.css` + `console-panels.css`（组件样式）、`city-dark-themes.css`（四套皮肤）。各方案的 URL 参数同 A，D 另有 `?page=overview|map|city|army|growth|intel|agent`。四套都在 1920×1080、1440×900、1280×720、1100×800、390×844 下逐页检查过：页面不滚动、无元素出现滚动条、无内容被裁切。

下文以方案 A 为例说明共同规则。

### 方案 A：`console.html` 单屏控制台

目标：二期功能全部塞进一页，**任何窗口尺寸都不出现竖向滚动条**（页面和面板内部都不滚动）。

布局：`100dvh` 固定外壳 = 顶栏 + 三栏 + 底部时间线。

| 区域 | 内容 | 现有界面对应 |
| --- | --- | --- |
| 顶栏 | 城池切换（下拉）· 五资源 + 人口（产量 / 仓满百分比 / 进度条）· 来袭警报 · 断粮 · 免战 · 集市 · 榜 · Agent 灯 · 账号菜单（改名 / 切换 / 重置 / 皮肤） | TopBar、CitySwitcher、ThemeSwitcher、ServerFeed 移到底栏 |
| 左栏「城务」 | 图标轨切换五个面板：城建（15 建筑格 + 选中建筑详情 / 连升 + 建造队列）、征兵（11 兵种表 + 队列）、科技、武将（列表 + 酒馆）、领地 | BuildQueue、Recruit、Tech、Hero、Territory；**建筑详情弹窗并入城建面板** |
| 中栏「地图」 | 世界 / 城内切换；图层开关（流寇·商队、黄巾、我的领地）；黄巾浮卡；图例；格数按容器尺寸实时计算，地图永远铺满 | MainViewPanel、WorldMapView、CityMapView、YellowTurbanPanel（浮卡）、MovingTargetPanel（图层） |
| 右栏「情报」 | 上：选中目标的详情与就地操作（掠夺 / 占领 / 侦察 / 截击 / 运输 / 调兵，含编队、随队将领、到达与埋伏判断）；未选中时是军情摘要。下：行军 / 战报 / Agent / 动态 四个分页列表 | **地块详情弹窗（WorldTileDialog）并入右栏**；WorldReports、Agent、Events |
| 底栏 | 建造 / 征兵 / 科技 / 行军四条时间线泳道 + 全服播报 | 新增（原先分散在各面板） |

弹窗规则（`console-modal.js`）：**操作就地做，详情才弹窗**。
- 就地：出征 / 侦察 / 截击 / 运输 / 调兵（右栏）、建造升级（左栏城建）、征兵、科技、武将、作战方针。
- 弹窗：战报详情（点战报行）、侦察报告、排行榜（顶栏「榜」）、离线日报（Agent 页签）——只读、内容多、偶尔看。
- 小浮层：集市兑换（锚在「集市」按钮下，点外面关闭）。
- 确认框：重置账号等不可撤销操作；NPC 来袭为顶部提醒条（带「增援」）。
- 弹窗统一 Esc / 点遮罩关闭，内容同样不滚动、超出分页。

其他已定：城建保留两处入口且选中同步——左栏城建格是常驻的紧凑入口（看世界地图时也能操作），中栏「城内」是大图视角，点建筑会跳到左栏城建并选中；地图等级数字默认隐藏，悬停 / 选中时显示，10 级（满级）金色常显。

不滚动的做法：长列表一律**按可用高度分页**（先渲染一条测真实行高，再算每页条数）；选中目标时右栏上半按内容高度展开、下半列表自动少放几条。战报 / 侦察报告详情、排行榜、离线日报仍用弹窗（弹窗内同样分页）。

断点：≥1600 加宽两侧；1280–1599 标准三栏；1024–1279 左栏收成图标轨、点图标弹出浮层，顶栏让出断粮 / 免战（右栏军情摘要里有）；< 1024 单窗格 + 底部「城务 / 地图 / 情报」分页签，选中目标时情报窗格整列给操作表单。

评审入口（URL 参数直接打开某个状态）：`?tile=wild|mover|own`、`&act=截击|运输…`、`&view=city`、`&left=build|recruit|tech|hero|terr`、`&intel=march|report|agent|event`、`&pane=city|map|intel`（窄屏）。已在 1920×1080、1440×900、1280×720、1100×800、390×844 下逐一检查：页面高度等于视口、无元素出现滚动条、无内容被裁切。

---

这些都是静态 DOM 布局稿，不是正式 React 应用。登录、建造和查询按钮只更新本页演示状态，不发起网络请求，不保存密码，不代表协议、业务数值或 Agent 身份认证已确定。确定布局后，再按项目约定搭建 React + TypeScript + Tailwind CSS + Rsbuild 的正式前端。
